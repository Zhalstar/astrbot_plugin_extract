## 🤝 介绍

对图片、视频、语音、文件等媒体的元数据进行解析

## 📦 安装

在astrbot的插件市场搜索astrbot_plugin_extract，点击安装即可

## ⌨️ 使用说明

### 命令表

|     命令      |        说明         |
|:-------------:|:------------------:|
| (引用消息)raw  | 获取原始数据    |
| (引用消息)解析  | 获取解析后的数据  |
